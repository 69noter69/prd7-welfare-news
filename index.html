ค้นหาข่าวเดี๋ยวนี้

ปุ่มนี้จะสั่งให้ระบบบน GitHub วิ่งหาข่าวทันที (ไม่ต้องรอ 08:00 น.) ใช้เวลาประมาณ 2–4 นาที ข่าวใหม่จะถูกรวมเข้ากับข่าวของวันนี้

ครั้งแรกต้องใส่ GitHub token ของคุณ 1 ครั้ง — token จะถูกเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น และส่งไปที่ GitHub เท่านั้น

สร้างได้ที่ github.com → Settings → Developer settings → Fine-grained tokens → เลือก repo นี้ → Repository permissions → Actions: Read and write
