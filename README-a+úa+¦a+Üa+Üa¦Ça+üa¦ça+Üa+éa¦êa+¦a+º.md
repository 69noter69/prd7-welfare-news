## ระบบนี้คืออะไร

ทุกเช้า **08:00 น.** ระบบจะทำงานเองโดยไม่ต้องมีใครสั่ง ตามลำดับนี้

1. ไปอ่านข่าวจากสำนักข่าวประมาณ 19 แห่ง และคำค้นหาอีกกว่า 40 คำ

3. ส่งข่าวที่เหลือให้ AI อ่าน จัดหมวด ให้คะแนน และเขียนสรุปภาษาไทย
4. เขียนผลลัพธ์ลงเว็บ ทีมงานเปิดดูได้ทันที

**ระบบจะไม่เอาข่าวจากเว็บและเพจของ สปข.7 เอง** เพราะเราคือผู้ผลิตข่าว ไม่ใช่ผู้ตามข่าว
(ข่าวจากสำนักข่าวกรมประชาสัมพันธ์ส่วนกลางยังเก็บไว้ตามปกติ)

## วิธีเพิ่มหรือลดแหล่งข่าวและคำค้นหา

แก้ไฟล์เดียวคือ **`config/sources.yaml`** แก้บนเว็บ GitHub ได้เลย ไม่ต้องโหลดลงเครื่อง

1. เข้า repo กดเข้าโฟลเดอร์ `config` กดไฟล์ `sources.yaml`
2. กดไอคอนรูปดินสอ ✏️ มุมขวาบน
3. แก้แล้วกด **Commit changes**

### เพิ่มคำค้นหา

หาหัวข้อ `google_news_queries:` แล้วเพิ่มบรรทัดใหม่ต่อท้าย

```yaml
google_news_queries:
  - บัตรสวัสดิการแห่งรัฐ
  - คำค้นใหม่ของคุณ        # <- เพิ่มแบบนี้
```

### เพิ่มสำนักข่าว

```yaml
feeds:
  - name: ชื่อสำนักข่าว
    url: https://ที่อยู่ของ-rss
```

### ลบแหล่งข่าวที่เสีย

ลบทั้ง 2 บรรทัด (`- name:` และ `url:`) ออกไปเลย อย่าลบแค่บรรทัดเดียว

### ⚠️ กฎ 3 ข้อของไฟล์นี้

1. **ห้ามกด Tab** ใช้เว้นวรรคเท่านั้น
2. **ขีด `-` ต้องเรียงตรงกัน** กับบรรทัดอื่นในกลุ่มเดียวกัน
3. **แก้ทีละนิด** แล้วรันทดสอบ อย่าแก้ทีเดียว 10 จุด

ถ้าแก้แล้วระบบพัง เข้า repo กดแท็บ **Commits** หาการแก้ครั้งก่อนหน้า แล้วกดย้อนกลับได้เสมอ

## ตัวเลขที่ปรับได้ (อยู่บนสุดของ `sources.yaml`)

| ค่า | ความหมาย | ค่าปัจจุบัน |
|---|---|---|
| `max_ai_items` | ส่งให้ AI อ่านไม่เกินกี่ข่าวต่อวัน — **ตัวคุมค่าใช้จ่ายหลัก** | 60 |
| `summary_words` | ความยาวสรุปที่สั่ง AI — ยิ่งยาวยิ่งแพง | 40-70 |
| `keep_min_score` | คะแนนขั้นต่ำที่จะขึ้นเว็บ (ข่าวทั่วประเทศ) | 45 |
| `keep_min_score_eastern` | คะแนนขั้นต่ำของข่าวภาคตะวันออก | 25 |
| `window_hours` | ย้อนดูข่าวหลังกี่ชั่วโมง | 26 |

**ข่าวเยอะเกินไป** → เพิ่ม `keep_min_score` เป็น 55
**ข่าวน้อยเกินไป** → ลด `keep_min_score` เป็น 35 หรือเพิ่ม `max_ai_items`

## ไฟล์สถิติสำหรับทำรายงาน

เปิดด้วย Excel ได้เลย (ดับเบิลคลิก)

| ไฟล์ | มีอะไร |
|---|---|
| `data/stats-daily.csv` | 1 บรรทัดต่อ 1 วัน — จำนวนครั้งที่ค้นหา ข่าวที่อ่าน ข่าวที่คัดมา ค่าใช้จ่าย |
| `data/stats-summary.csv` | ยอดรวมสะสมทั้งหมดตั้งแต่วันแรก |

**วิธีโหลด** เข้า repo → กดโฟลเดอร์ `data` → กดชื่อไฟล์ → กดปุ่ม **Download raw file** (ไอคอนลูกศรลงมุมขวา)

**หมายเหตุ 2 ข้อ**

- ช่อง **ครั้งที่ค้นหา** ปกติจะเป็น **1** ทุกวัน เพราะระบบตั้งเวลารันวันละครั้ง จะมากกว่า 1 เมื่อมีคนกดปุ่ม "ค้นหาข่าวเดี๋ยวนี้" เอง
- **ข่าวที่แสดงทั้งหมด** กับ **ข่าวไม่ซ้ำ** ต่างกัน ข่าวเรื่องเดียวที่แสดง 3 วันติดจะนับเป็น 3 ในช่องแรก แต่นับเป็น 1 ในช่องหลัง

## การส่งมอบให้คนอื่นดูแลต่อ

1. ผู้รับสมัครบัญชี GitHub และบัญชี Anthropic ของหน่วยงาน
2. เจ้าของเดิมเข้า **Settings → Transfer ownership**
3. ผู้รับใส่ `ANTHROPIC_API_KEY` ใน **Settings → Secrets and variables → Actions** ใหม่
   ⚠️ **Secrets ไม่ติดไปกับการโอน** ต้องใส่ใหม่เสมอ
4. เปิด **Settings → Pages → Source: main / (root)** อีกครั้ง
5. เข้าแท็บ **Actions** กด enable workflows แล้วกด **Run workflow** ทดสอบ 1 ครั้ง

## ข้อกำหนดการใช้ข่าว

ระบบแสดงเฉพาะ **หัวข้อ** และ **สรุปย่อ** เท่านั้น ไม่เก็บและไม่แสดงเนื้อข่าวเต็ม
ทุกข่าวมีลิงก์กลับไปยังต้นฉบับเสมอ ลิขสิทธิ์เป็นของสำนักข่าวต้นทาง

## สำหรับผู้ดูแลด้านเทคนิค

```
python -m collector.main run                    # เก็บข่าวประจำวัน
python -m collector.main run --no-ai            # ทดสอบโดยไม่เรียก AI (ฟรี)
python -m collector.main run --date 2026-09-09  # เก็บย้อนหลังวันที่ระบุ
python -m collector.main backfill --days 3      # เติมข้อมูลย้อนหลัง 3 วัน
python -m collector.main check-feeds            # ทดสอบว่าแหล่งข่าวไหนใช้ได้
python -m pytest tests/ -q                      # รันชุดทดสอบ
```

ไฟล์ที่ระบบเขียน: `data/YYYY-MM-DD.json` · `data/index.json` · `data/_seen.json` ·
`data/stats-daily.csv` · `data/stats-summary.csv` · `data/last_run.json`

**ห้ามลบ `data/_seen.json`** เป็นทะเบียนข่าวที่เคยเจอ ใช้ทำป้าย "ตามต่อจาก…" และนับข่าวไม่ซ้ำ
